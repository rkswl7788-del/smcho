# FRD — 현장별 공정·기성 대시보드

## 한눈에 보기

1. 화면에서 무엇을 누르면 어떻게 동작하는지를 기능 13개로 나눠 표로 정리했습니다.
2. 월·지역·유형·현장 필터 하나가 현황·추이·비교표·CSV·AI에 똑같이 적용됩니다.
3. 누적기성액(월말까지 쌓인 금액)과 당월기성액(전월 대비 늘어난 금액)은 이름·계산·표시를 분리하고, 전월이 없으면 "계산 불가"로 표시합니다.
4. 비교표의 행을 펼치면 공사기간·기록된 상황·대응 계획이 같은 페이지 안에서 열립니다.
5. 오류가 나면 지금 자료와 필터를 유지하고, 어느 행의 무엇이 문제인지 안내합니다. AI가 실패해도 대시보드와 CSV는 계속 씁니다.

> 교육용 가상 자료 기준입니다. 단위·계산 기준은 `data/데이터설명.md`, 예시 숫자는 `data/검산표.md`를 따릅니다. `(AI 결정)`은 규칙에 없어서 제가 정한 것입니다.

## 1. 기능별 표

공통 규칙: 금액은 백만원(천 단위 쉼표), 비율은 소수 첫째 자리 %, 공정차이는 부호를 붙인 pp(예: −10.7pp, +1.7pp)로 표시합니다. 자료가 없거나 분모가 없으면 0이 아니라 "계산 불가" 또는 "자료 없음"으로 표시합니다.

| 번호 | 기능 | 사용자가 하는 일 | 프로그램이 하는 일 | 화면에 보이는 결과 | 오류·예외일 때 |
|---|---|---|---|---|---|
| F1 | 필터 (월·지역·유형·현장) | 화면 위쪽에서 월, 지역, 공사 유형, 현장을 고릅니다. "필터 초기화"를 누릅니다. | 고른 조건을 모든 페이지가 함께 쓰는 하나의 범위로 저장합니다. 지역·유형을 바꿔 고른 현장이 범위에서 빠지면 현장을 "전체"로 되돌립니다. 월을 바꿔도 지역·유형·현장은 유지합니다. 현장 목록은 지금 지역·유형에 맞는 현장만 보여 줍니다. "필터 초기화"는 자료의 가장 늦은 월(처음 자료는 2026-09)·전체 지역·전체 유형·전체 현장으로 되돌립니다. | 처음 화면은 2026년 9월·전체입니다. 모든 페이지 위쪽에 같은 범위가 보입니다. 현장이 자동으로 "전체"로 바뀌면 그 사실을 한 줄로 알려 줍니다(AI 결정). | 고른 범위에 해당 월 자료가 없으면 "자료 없음"을 보여 주고 숫자를 0%로 채우지 않습니다. 필터를 바꾸면 AI 이전 답변을 지웁니다(F12). |
| F2 | 자료 가져오기 — 파일 고르기·검사 | 자료 가져오기 페이지에서 CSV 또는 JSON 파일을 고릅니다. | 파일을 브라우저에서 읽고 전체를 검사합니다(6장 검사 항목). 이 단계에서는 지금 자료를 바꾸지 않습니다. CSV는 메타데이터(단위 정보)가 없으므로 "`데이터설명.md`의 단위·필드 기준을 적용했습니다"라고 안내합니다. | 단계 표시(① 파일 선택 ② 검사 결과·미리보기 ③ 완료)와 검사 결과(행 수·열 수·월 범위·현장 수·오류 N건·경고 N건)가 보입니다. | 오류가 하나라도 있으면 반영 버튼을 막고, "몇 행·어느 열·무슨 문제"를 목록으로 보여 주며 "지금 자료는 유지됩니다"를 알립니다. csv·json이 아닌 파일, 비어 있는 파일, 5MB 초과 파일(AI 결정)은 검사 전에 거절합니다. |
| F3 | 자료 가져오기 — 미리보기·반영·취소 | 미리보기 표를 확인하고 "반영하기" 또는 "취소하고 기존 자료 유지"를 누릅니다. | 검사를 통과한 파일만 반영할 수 있습니다. 반영하면 지금 자료 전체를 새 자료로 바꿉니다(누적하지 않음). 반영 후 필터를 가장 늦은 월·전체로 되돌리고 AI 답변을 지웁니다. 취소하면 아무것도 바꾸지 않습니다. | 미리보기는 계산 열 4개를 포함한 19개 열 표입니다. 기준 월 12개 현장 보기와 전체 행 보기를 고를 수 있습니다(AI 결정). 완료 단계에 "144행으로 교체했습니다"가 보입니다. CSV를 가져온 뒤 같은 JSON을 가져와도 144행입니다. | 월 누락이 있으면 경고만 표시하고 "확인 가능한 행만 집계했습니다"를 알립니다. 전월 행이 없는 현장·월은 당월기성액이 "계산 불가"입니다. 반영 중 문제가 생기면 지금 자료를 유지합니다. |
| F4 | 현황 — 큰 숫자 4개 | 현황 요약 페이지를 엽니다. | 지금 범위의 선택 월 자료로 전체 기성률, 계획 공정률, 실제 공정률, 공정차이를 계산합니다(5장). 기성률 카드에는 누적기성액·계약금액·당월기성액을 함께 보여 줍니다. 정상·주의·점검 곳 수도 계산합니다. | 큰 숫자 4개와 상태 곳 수가 한 줄로 나옵니다. 9월 전체는 67.2% · 73.2% · 71.2% · −2.0pp, 정상 6·주의 3·점검 3입니다. | 범위에 자료가 없으면 4개 모두 "자료 없음". 당월기성액을 계산할 수 없으면 "계산 불가"(2025-10은 항상 해당)이고, 누적 지표는 그대로 표시합니다. |
| F5 | 현황 — 점검 현장 순위 | 순위 목록을 봅니다. | 지금 범위·선택 월에서 공정차이가 −5pp 이하인 현장만 골라 공정차이가 작은 순, 같으면 현장 ID 순으로 줄 세웁니다. | 한 줄에 순번, 현장 ID·이름, 계획·실제 공정률, 공정차이, 기성률이 보입니다. 9월 전체는 D(−10.7pp) → I(−7.6pp) → K(−5.4pp)입니다. | 점검 현장이 없으면 "점검 대상 없음" 상태 화면을 보여 줍니다. 자료가 없으면 순위 대신 "자료 없음"을 보여 줍니다. |
| F6 | 현황 — 월별 추이 | 월을 바꾸거나 차트에 마우스를 올립니다. | 지역·유형·현장 범위로 시작 월부터 선택 월까지 매월 따로 집계합니다. 선은 계획·실제 공정률(계약금액 가중평균), 막대는 당월기성액입니다. 월별 누적기성액을 합치지 않습니다. | 월 위에 마우스를 올리면 그 달의 당월기성액·누적기성액·계획·실제 공정률이 말풍선으로 나옵니다. 9월 전체는 10월~9월 12개월입니다. 2025-10 막대는 비워 두고 "계산 불가"로 표시합니다. | 월 자료가 빠져 있으면 그 달을 표시하지 않고 "확인 가능한 행만 집계" 안내를 붙입니다. 선택 현장 중 하나라도 전월이 없는 달은 막대를 비우고 "계산 불가"로 표시합니다. |
| F7 | 점검 순위 줄 누르기 | 순위의 한 줄(예: D)을 누릅니다. | 현장별 비교표 페이지로 이동하고, 같은 필터를 유지한 채 그 현장 줄을 강조하고 펼칩니다. | 비교표에서 D 줄에 강조선이 보이고 공사기간·기록된 상황·대응 계획이 열려 있습니다. | 그 현장이 지금 범위에 없으면 이동하지 않습니다(순위가 같은 범위에서 만들어지므로 정상 상태에서는 생기지 않습니다). 필터를 바꾸면 강조를 해제합니다(AI 결정). |
| F8 | 현장별 비교표 | 비교표 페이지를 엽니다. | 지금 범위·선택 월의 현장을 현장 ID 순으로 한 줄씩 보여 줍니다. 마지막에 합계·가중평균 줄을 붙입니다. 상태는 색과 글자("점검"·"주의"·"정상")로 구분합니다. | 열: 현장 ID·이름 / 지역 / 공사 유형 / 당월 주요 공종 / 계약금액 / 누적기성액 / 당월기성액 / 기성률 / 계획 / 실제 / 공정차이 / 상태 / 기록 보기. 9월 전체는 12행입니다. | 자료가 없으면 표 대신 "자료 없음". J의 7월 당월기성액 0.0은 정상값으로 "0.0"을 표시하고, 전월이 없는 값은 "계산 불가"로 구별합니다. |
| F9 | 행 펼침 (상황·대응 기록) | 행 오른쪽 화살표를 누릅니다. 다시 누르면 접습니다. | 같은 페이지 안에서 그 행 아래에 기록을 엽니다. 별도 상세 페이지나 새 창을 만들지 않습니다. 여러 행을 동시에 펼칠 수 있습니다(AI 결정). | 공사기간(착공일 ~ 계약상 준공일), 당월 주요 공종, 특이사항 분류, "기록된 상황", "기록된 대응 계획"이 보입니다. 계약상 준공일은 "예정 일정이며 실제 완료일이 아님"이라고 함께 적습니다. | 기록 문구가 비어 있으면 가져오기 단계에서 막으므로 펼침 중 빈 칸은 생기지 않습니다. 펼침 상태는 필터를 바꾸면 모두 접습니다(AI 결정). |
| F10 | CSV 내보내기 | 위쪽 "CSV 내보내기"를 누릅니다(모든 페이지에 있음). | 지금 필터와 같은 범위(선택 월·지역·유형·현장)의 원본 15개 열에 기성률·공정차이·상태·당월기성액 4개 열을 더해 파일로 만듭니다. 한글이 깨지지 않게 UTF-8 BOM으로 저장합니다. | 9월 D만 고르면 헤더 아래 데이터 1행, 9월 인천·공동주택이면 2행입니다. 숫자는 쉼표 없이 원래 단위(백만원, %) 그대로 들어갑니다. 파일 이름은 `현장공정기성_2026-09_전체.csv` 형식입니다(AI 결정). | 범위에 자료가 없으면 버튼을 막고 "내보낼 자료가 없습니다"를 안내합니다. 계산 불가인 당월기성액은 0이 아니라 빈 칸으로 내보냅니다(AI 결정). |
| F11 | AI에게 묻기 — 질문 | 예시 질문을 누르거나 질문을 직접 쓰고 "질문 전송"을 누릅니다. | 서버에서 Gemini API(다른 프로그램의 기능을 요청해서 쓰는 방법)를 호출합니다. 보내는 자료: 지금 범위 선택 월의 원문 행, 프로그램이 계산한 지표, 추이 질문일 때 시작 월~선택 월의 월별 요약입니다. 한 현장을 골랐을 때는 그 현장의 월별 기록 원문도 보냅니다. 추이 질문은 질문에 "추이·회복·변화·늘·줄·지난·월별·왜 …않" 같은 말이 있는지로 판단합니다(AI 결정). | 위쪽에 지금 범위(월·지역·유형·현장)가 보입니다. 예시 질문은 "D가 늦어진 원인과 대응은?", "점검 현장은 어디인가요?", "D는 회복 중인가요?"입니다. 기다리는 동안 "AI 답변을 기다리는 중"이 보이고 질문 입력은 잠깁니다(AI 결정). | 빈 질문은 전송 버튼을 막습니다. 질문은 500자까지(AI 결정). 자료 없음 상태에서는 질문하지 않도록 막습니다. |
| F12 | AI 답변·근거 표시와 범위 변경 | 답변과 근거를 읽습니다. 필터를 바꿉니다. | AI는 기록된 상황·계획된 대응을 근거로만 설명합니다. 실제 준공일·미수금 같은 자료 밖 내용은 "자료 없음"으로 답하게 합니다. 근거 패널은 AI가 쓴 글이 아니라 프로그램이 보낸 값을 그대로 보여 줍니다. 필터를 바꾸면 이전 답변을 지웁니다. 요청 중에 필터가 바뀌면 늦게 온 응답을 버리고 새 범위에 표시하지 않습니다. | 답변과 함께 기준 월, 현장 ID, 근거 숫자(계획·실제·공정차이·기성률 등), 참고한 기록 필드(기록된 상황·계획된 대응)가 보입니다. D의 원인 질문에는 공급 정상화 후에도 남은 지연과 주간 확인 계획을 기록대로 설명합니다. | 보낸 자료 밖의 월·현장을 물으면 보낸 범위를 안내하고 숫자·원인을 만들지 않습니다. 6장 AI 오류 때 "AI 연결 실패" 상태를 보여 주고 "대시보드와 CSV는 계속 쓸 수 있습니다"를 안내합니다. |
| F13 | 페이지 이동·빈 상태 | 위쪽 메뉴(현황 요약·현장별 비교표·자료 가져오기·AI에게 묻기)를 누릅니다. | 같은 범위를 유지한 채 페이지만 바꿉니다. 자료가 없는 처음 상태에서는 가져오기 안내만 보여 줍니다. | 처음 열면 모든 페이지에 "자료 없음 — 자료 가져오기에서 파일을 가져오세요"와 이동 버튼이 보입니다. 위쪽에 기준 월과 "점검 현장 N곳"이 항상 보입니다(AI 결정). | 새로고침하면 자료가 사라지므로 처음 상태로 돌아갑니다. 이때 파일을 다시 가져옵니다. |

## 2. 역할별 표

| 역할 | 맡는 일 | 맡지 않는 일 |
|---|---|---|
| 사용자(본사 공무팀 담당자) | 파일 선택, 필터 선택, 반영·취소 결정, 기록 펼치기, CSV 내려받기, AI에 질문하기 | 숫자를 직접 계산하지 않습니다. 상태를 손으로 판정하지 않습니다. |
| 프로그램(계산·검사) | 파일 검사, 기성률·공정차이·상태·당월기성액·가중평균·추이 계산, 점검 순서 결정, 필터 범위 관리, CSV 만들기, AI에 보낼 자료 고르기, 근거 패널 만들기, 오류 안내 | 자료에 없는 값을 추정하지 않습니다. 빈칸을 0으로 바꾸지 않습니다. |
| AI(설명) | 프로그램이 보낸 숫자와 기록된 상황·계획된 대응을 근거로 설명 | 계산, 상태 판정, 원인 확정, 완료 사실 단정, 실제 준공일·미수금·수금액·기상 실측 답변, 보내지 않은 월·현장 답변 |

## 5. 계산 규칙 표

계산은 반올림 없이 끝까지 하고, 화면·CSV에 보이는 마지막 단계에서만 소수 첫째 자리로 반올림합니다. (근거: `데이터설명.md` 표시 규칙)

| 항목 | 계산 방법 | 예시 (검산표 숫자) |
|---|---|---|
| 현장 기성률 | 누적기성액 ÷ 계약금액 × 100 | 9월 D: 50,384.4 ÷ 72,600 × 100 = 69.4% |
| 현장 공정차이 | 실제공정률 − 계획공정률 (pp) | 9월 D: 75.8 − 86.5 = −10.7pp |
| 상태 | 0pp 이상 정상 / −5pp 초과 0pp 미만 주의 / −5pp 이하 점검. 공정률을 0.1 단위 정수로 바꿔 판정해 소수 오차가 없게 합니다. | 계획 70·실제 70 → 정상, 65.1 → 주의(−4.9), 65 → 점검(−5.0) |
| 점검 순서 | 점검 현장만 공정차이 오름차순, 같으면 현장 ID 오름차순 | 9월: D(−10.7) → I(−7.6) → K(−5.4) |
| 전체 기성률 | 선택 범위의 누적기성액 합계 ÷ 계약금액 합계 × 100 (한 달만) | 9월: 424,063.4 ÷ 630,700 × 100 = 67.2% |
| 전체 계획·실제 공정률 | 계약금액 가중평균: Σ(계약금액 × 공정률) ÷ 계약금액 합계 | 9월: 73.2% · 71.2% |
| 전체 공정차이 | 반올림 전 가중 실제 − 반올림 전 가중 계획. 화면에 보이는 두 비율을 다시 빼지 않습니다. 전체에는 상태를 붙이지 않고 정상·주의·점검 곳 수만 보여 줍니다(AI 결정). | 9월: −2.0pp |
| 누적기성액 | 자료의 cumulativeEarned를 그대로 씁니다. 월말까지 쌓인 금액이며 수금액이 아닙니다. 여러 달을 더해 총액으로 쓰지 않습니다. | 9월 전체: 424,063.4백만원 |
| 당월기성액 (현장) | 당월 누적기성액 − 바로 전월 누적기성액. 전월 행이 없으면 계산 불가(0이나 누적액으로 대신하지 않음). 결과가 0이면 정상값 0.0입니다. | J의 7월: 26,308.8 − 26,308.8 = 0.0 / 2025-10: 계산 불가 |

| 월별 추이 | 지역·유형·현장 범위로 시작 월~선택 월을 매월 따로 위 규칙으로 집계 | 9월 전체: 12개월, 8월 누적 395,184.7 → 9월 424,063.4 |
